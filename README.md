# Roguelike

Простой пошаговый рогалик в терминале на Python с использованием библиотеки `rich`.

Игрок исследует процедурно генерируемые подземелья, сражается с врагами, собирает золото и прокачивается у торговца. Цель — дойти до 5-го этажа и победить босса.

---

## Что внутри

*   **Процедурная генерация карты** — каждое подземелье уникально.
*   **5 типов монстров**: Гоблин, Танк, Стрелок, Бродяга и Босс.
*   **Умный ИИ врагов** — монстры атакуют только в радиусе агра и преследуют игрока.
*   **Пошаговая боевая система** с контратаками.
*   **Магазин у торговца** — HP, урон и «Меч Бога».
*   **Сундуки, ловушки и аптечки** на карте.
*   **Система этажей** — с каждым уровнем враги становятся сильнее.
*   **Цветной вывод** через библиотеку `rich`.
